## 🏃 What Is Fitrail?

**Fitrail** is a free, open-source, **privacy-first fitness, sleep, and workout tracker** with **route privacy**. It helps you follow your training and rest without handing over a detailed record of where you go.

Built by [LYF Mail](https://lyfmail.com), a [privacy-first digital wellness platform](https://lyfmail.com) serving 50,000+ subscribers across India since 2020, Fitrail extends our mission of **"Every Choice Shapes Tomorrow"** into everyday tools that people can trust.

---

## 🧭 Why Fitrail Exists

- 📍 **Workout routes reveal where you live, work, and spend time.**
- 😴 **Fitness and sleep data** are deeply personal.
- 📊 **Most fitness apps** build accounts, profiles, and sharing features around your data.

**Fitrail tracks fitness, sleep, and workouts while keeping your routes private** — built on LYF Mail's privacy-first principles.

- **🏋️ Fitness & Workout Tracking** — Keep a record of your training in one place.

## 🚀 Quick Start Guide

### For Users

1. **Visit** [fitrail.lyfmail.com](https://fitrail.lyfmail.com).
2. **Start using Fitrail** straight from your browser.
3. **Add it to your home screen** if your browser offers an install option, for quick access.

### For Developers

1. **Clone the repository**
```bash
git clone https://github.com/lyfmail-official/fitrail.git
cd fitrail
```

2. **Serve locally** with any static file server
```bash
# Python 3
python -m http.server 8080

# Or with Node.js
npx serve .
```

3. **Open in your browser**
```
http://localhost:8080
```

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for contribution guidelines.

## 🤝 Contributing to Fitrail

Fitrail welcomes contributions that respect our core principles:

- **Privacy-first** — never introduce tracking, analytics, or unnecessary data collection.
- **Minimal dependencies** — prefer built-in web platform features over heavy frameworks.
- **Performance-focused** — optimize for low-end devices, slow networks, and limited battery.
- **Accessibility-first** — every feature must work for users with disabilities.
- **Location-respectful** — never add features that expose or transmit a user's routes.

Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) before submitting pull requests. To report a vulnerability, see [`SECURITY.md`](SECURITY.md).

## 💬 Frequently Asked Questions

**Q: Is Fitrail really free to use?**  
A: Yes. Fitrail is free to use and open source under the MIT License. It is a project by [LYF Mail](https://lyfmail.com), committed to making useful privacy-first tools accessible to everyone.

**Q: How does Fitrail handle my data?**  
A: Fitrail is built on LYF Mail's **privacy-first principles**: collect as little data as possible and keep control with the user. Because Fitrail is open source, you can inspect exactly how it works in the [source code](https://github.com/lyfmail-official/fitrail).

**Q: What is route privacy?**  
A: Route privacy means Fitrail is designed so that **your workout routes remain under your control** instead of becoming a location history held by a third party. See the source code for exactly how routes are handled.

**Q: Is Fitrail a medical device?**  
A: No. Fitrail is a **fitness and wellness tool**, not a medical device. Consult a healthcare professional before starting a new exercise programme or if you have concerns about your health or sleep.

**Q: Can I contribute to Fitrail?**  
A: Yes. We welcome developers, designers, writers, translators, and accessibility advocates. Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) first.

**Q: How do I report a bug or a security issue?**  
A: Open a [GitHub issue](https://github.com/lyfmail-official/fitrail/issues) for bugs. For security vulnerabilities, **do not** open a public issue — follow [`SECURITY.md`](SECURITY.md).
